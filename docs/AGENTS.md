# Documentation Agent Guide

Applies to `docs/**`. Read the root `AGENTS.md` first.

These documents are operational source material for future maintainers and coding agents. Keep them concise, dated where behaviour is time-sensitive, and evidence-based.

## Required upkeep

When a YouTube compatibility fix changes any of the following, update the matching document:

- client identity/token/challenge behaviour -> `client-profiles.md`;
- investigation/review workflow -> `maintenance.md`;
- useful upstream/fork/other-language source -> `reference-repositories.md`.

Do not state that a client or fork is "working" indefinitely. Use language such as "observed/reviewed on YYYY-MM-DD" and include the evidence or issue/commit that motivated the statement.

The reference repository inventory is a research map, not an endorsement list. Re-check activity and relevance during every significant compatibility investigation.
